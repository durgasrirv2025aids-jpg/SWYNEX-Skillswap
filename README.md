Problem Statement:
Students have different skills and learning interests, but finding suitable students to teach or learn new skills is difficult. There is no centralized platform for students to share knowledge and exchange skills. Therefore, a web-based SkillSwap platform is needed to connect students and encourage collaborative learning.

Proposed Solution:
SkillSwap is a full-stack web application that connects students who want to teach their skills with students who want to learn new skills.

The system provides the following features:
**Student Registration and Login:** Students can create accounts and securely log in.
**Student Profiles:** Students can create and manage their profiles.
**Add Skills:** Students can add skills they can teach and skills they want to learn.
**Find Learning Partners:** Students can find suitable partners based on matching skills.
**Exchange Requests:** Students can send, accept, or reject skill exchange requests.
**Track Connections:** Students can view their accepted learning partners.
